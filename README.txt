نظام أحمد — ذاكر غصب عنك
==========================

تشغيل الموقع:
1) فك ضغط الملف nizam_ahmed.zip.
2) افتح مجلد nizam_ahmed في Visual Studio Code.
3) تأكد أن الملفات التالية موجودة في نفس المجلد:
   index.html
   style.css
   script.js
   assets/
4) ثبّت إضافة Live Server في VS Code.
5) اضغط بزر الفأرة الأيمن على index.html ثم Open with Live Server.

الوظائف الموجودة:
- مؤقت بومودورو 25 دقيقة وتركيز / 5 دقائق راحة.
- مهام مع إضافة وإنجاز وحذف وتصنيف حسب المادة والوقت.
- نقاط XP ومستويات.
- جدول أسبوعي للدروس والجيم.
- خطة يومية قابلة للتعديل.
- تسجيل درس ومواعيد مراجعة تلقائية بعد 1 و3 و7 و14 و30 يومًا.
- رسوم بيانية محلية لدقائق التركيز.
- حفظ البيانات داخل المتصفح باستخدام localStorage.

ملاحظات:
- البيانات محفوظة على نفس المتصفح والجهاز، وليست سحابية.
- تسجيل الدخول الحقيقي غير مفعّل في هذه النسخة.
- أوقات الصلاة ليست محسوبة تلقائيًا؛ اضبطها حسب تقويم الصلاة المحلي.
- مواعيد المدرسة والجيم في الإعدادات افتراضية وقابلة للتعديل.
- أصول الصور اختيارية؛ لو لم تكن موجودة سيظل التصميم يعمل بخلفيات متدرجة.
